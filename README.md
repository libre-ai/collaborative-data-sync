# Libre AI Collaborative Data Sync

[Français](README.fr.md)

Collaborative applications need to exchange document changes while keeping track of what each client has received. This project explores synchronization for developers building shared editing experiences. It focuses on revisions, concurrent changes and reconnection, including the ordinary disruptions that occur when clients work with intermittent connectivity.

## Intended uses

- Exchange edits between two clients working on the same shared document.
- Recover missing changes after a disconnection without applying duplicate updates.
- Handle changes in access while keeping documents and organizations separate.

## Availability

This repository currently contains documentation only; no installable tool is available.
