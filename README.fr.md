# Libre AI Collaborative Data Sync

[English](README.md)

Les applications collaboratives doivent échanger les modifications tout en suivant ce que chaque client a reçu. Ce projet explore la synchronisation pour les développeurs d’expériences d’édition partagée. Il se concentre sur les révisions, les changements concurrents et la reconnexion, notamment lorsque la connexion des clients est intermittente.

## Usages visés

- Échanger les modifications de deux clients travaillant sur un même document partagé.
- Récupérer les changements manquants après une déconnexion sans appliquer de doublons.
- Gérer les changements d’accès en maintenant la séparation des documents et des organisations.
